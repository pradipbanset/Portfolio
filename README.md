# Pradip Basnet — AI Portfolio 🤖🇳🇵

An AI-powered interactive portfolio where visitors can chat with my memoji avatar to learn about my projects, skills, and experience.

Built with Next.js 15, Groq LLM, Framer Motion, and WebGL fluid cursor.

## 🚀 Run locally


git clone https://github.com/pradipbanset/Portfolio.git
cd Portfolio
pnpm install


Create \`.env.local\`:

GROQ_API_KEY_1=your_key
GROQ_API_KEY_2=your_key


bash
pnpm dev


## 🛠 Tech Stack
- Next.js 15, TypeScript, Tailwind CSS
- Groq LLM (llama-3.3-70b-versatile)
- Framer Motion, WebGL fluid cursor
- Vercel AI SDK
